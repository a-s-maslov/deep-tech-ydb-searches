# Deep Tech Night: полнотекстовый, векторный и гибридный поиск в YDB

Проект содержит воспроизводимый стенд воркшопа: подготовку русскоязычного
корпуса, схему и индексы YDB, Go-генератор нагрузки, оценку качества поиска и
единый сценарий демонстрации эластичности и отказоустойчивости.

Данные не включены в Git. Они собираются из зафиксированных публичных
источников: текстов и qrels MIRACL RU, готовых document embeddings Castorini и
соответствующего публичного mDPR checkpoint для query embeddings. Синтетические
вектора и облачные модели не используются.

## Что демонстрирует проект

- полнотекстовый индекс `fulltext_relevance` с русской морфологией;
- векторный индекс `vector_kmeans_tree` для 768-мерных mDPR-векторов;
- гибридный запрос `HybridRank`, объединяющий обе ветки;
- параллельный поток параметризованных `UPSERT` и проверки индекса;
- split полнотекстового индекса по нагрузке;
- рост пропускной способности после добавления dynamic-узлов;
- поведение нагрузки при отказе диска, процесса, сервера и трёх узлов ДЦ;
- общие графики клиентских и серверных метрик с аннотациями этапов.

Проект не создаёт сам кластер YDB. Управление нагрузкой, узлами, хаосами,
VictoriaMetrics и Grafana выполняет соседний клон
[`a-s-maslov/chaos-md`](https://github.com/a-s-maslov/chaos-md).

## Быстрый путь

Требования: Linux, Python 3.11+, Go 1.24, около 60 ГБ свободного места на время
первой подготовки данных и доступ к кластеру YDB с полнотекстовым, векторным и
гибридным поиском.

Клонировать проекты рядом:

```bash
git clone https://github.com/a-s-maslov/deep-tech-ydb-searches.git
git clone https://github.com/a-s-maslov/chaos-md.git
cd deep-tech-ydb-searches
```

Создать локальные конфиги из примеров и заполнить endpoint, профиль YDB и
параметры стенда:

```bash
cp config/workload.stand.example.json config/workload.stand.json
cp ../chaos-md/env.example.sh ../chaos-md/env-stand.sh
cd ../chaos-md && ./switch-config.sh stand
cp workload/manager.env.example.sh workload/env.local.sh
cd ../deep-tech-ydb-searches
```

Полная первичная подготовка выполняется одной командой из корня проекта. Она
пересоздаёт только таблицу из `table_path`, поэтому требует явного подтверждения:

```bash
./scripts/demo.sh bootstrap --yes
```

Перед повторным показом уже загруженного стенда:

```bash
./scripts/demo.sh prepare
./scripts/demo.sh preflight
./scripts/demo.sh stage overview
```

Точный порядок действий, ожидаемые результаты и восстановление после сбоев
находятся в [операторском сценарии](docs/demo.md). Чистое развёртывание и
настройка локальных секретов описаны в [deployment](docs/deployment.md).

## Данные

Доступны два независимых детерминированных профиля:

| Профиль | Документы | Назначение |
|---|---:|---|
| `baseline-50k` | 50 000 | быстрый локальный smoke-test |
| `scale-1m` | 1 000 000 | основной профиль воркшопа |

Каждый профиль содержит все размеченные документы для 1 252 русских
dev-запросов MIRACL и детерминированный фон из того же корпуса. Профили можно
загружать независимо; `scale-1m` не наращивает уже существующую таблицу.

```bash
bash scripts/dataset.sh build baseline-50k
bash scripts/dataset.sh status baseline-50k

# Основной профиль; первая загрузка исходного индекса около 27 ГБ.
bash scripts/dataset.sh build scale-1m
```

Python используется только для подготовки файлов и offline-оценки. Все
операции с YDB выполняет Go-бинарник. Подробная модель данных и распределение
ответственности описаны в [архитектуре](docs/architecture.md).

## Проверенный результат качества

На профиле `scale-1m` и всех 1 252 запросах получены:

| Метод | qrel Recall@30 | nDCG@10 |
|---|---:|---:|
| Full-text | 0,853 | 0,545 |
| YDB vector ANN | 0,827 | 0,662 |
| Hybrid | 0,894 | 0,668 |

Формальный ANN recall@30 относительно полного exact inner-product top-30 —
`0,825`. Это не тот же показатель, что qrel Recall: первый измеряет точность
приближённого векторного индекса, второй — полноту относительно экспертной
разметки MIRACL.

Методика, полный набор метрик, SHA-256 отчётов и обоснование параметров индекса
и запросов собраны в [quality/README.md](quality/README.md). Короткие ответы о
ML-части и интерпретации результатов — в [FAQ](docs/faq.md).

```bash
cd ..
python -m pytest -q
bash tests/dataset-control-smoke.sh
bash tests/demo-control-smoke.sh
```

```bash
./scripts/demo.sh preflight
```
